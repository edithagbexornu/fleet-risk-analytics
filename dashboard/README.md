# Power BI Dashboard

This folder contains the Power BI dashboard developed for the Fleet Risk Analytics case study.

## Dashboard Objectives

The dashboard supports analysis of:

- Driver risk levels
- Unsafe driving-event patterns
- Geographic concentrations of risk
- Driver mileage and fuel efficiency
- Risk patterns across truck models
- High-risk driver identification

## Key Metrics

- **Total Observations:** 8,000
- **Unsafe Events:** 457
- **Normal Events:** 7,543
- **Risk Factor:** (Unsafe Events / Total Miles) × 1,000,000

## Dashboard File

`fleet_risk_dashboard.pbix`

The Power BI file contains an interactive analytical report for exploring fleet safety and driver-risk patterns.
