# Dataset

This folder contains the fleet operational and telematics datasets used in the analysis.

## Files

- `geolocation.csv` — Driving-event and geographic data, including driver/truck IDs, event classifications, location, velocity, and event indicators.
- `trucks.csv` — Historical truck mileage and fuel-consumption data.
- `trucks_mg.csv` — Truck-level mileage and fuel data used for analytical processing.

The datasets support analysis of driver risk, unsafe driving events, geographic risk patterns, vehicle characteristics, mileage, and fuel consumption.
